# ADR-0008: WebSocket event names

- **Status:** Superseded by ADR-0025
- **Date:** 2026-11 (Milestone 1, deferred)

## Context
WORKFLOW.md used `new-message`, CLAUDE.md used `message:new`. The decision was deferred to the messaging milestone.

## Decision
Resolved early by ADR-0025 (`resource:past-tense-verb`, e.g. `message:created`), because the realtime design was reviewed as a whole during the system design review.
